# 타사 카드 즉시결제

직접 수행할 수 없는 요청임을 안내하고 가능한 대안을 제공한다.

## Instructions
1. 사용자 질의에서 요청 내용과 수행 불가 사유(정책/권한/데이터 범위)를 파악합니다.
2. `other_card_usage_inquiry` 툴을 호출해 마이데이터 소비내역 기반 타사 카드 이용금액을 조회합니다.
3. 요청을 직접 수행할 수 없는 이유를 한 문장으로 정중히 안내합니다.
4. 수행 가능한 대안(관련 조회, 화면 이동, 객관적 정보 제공)을 제시합니다.
5. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

> 훅: 이 스킬은 `scripts/hook.py`를 제공합니다. 툴 호출 전 `before_tool`(파라미터 검증·실행형 가드), 호출 후 `after_tool`(오류·재시도 판단), 응답 전 `finalize`(문구 템플릿)를 실행하세요. MCP 서버의 `run_skill_hook` 툴로 원격 실행할 수 있습니다.

## 응답 가이드
- 자산 > 소비내역에서 문의한 카드이용내역 확인하여 안내
- 삼성카드의 즉시결제는 해당 카드사에서 진행가능함을 안내

## 예외 처리
- 사용자가 대안을 원하지 않는 경우: 정중히 마무리합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

## 유저향 최종 안내 문구
제한 안내: "요청하신 {작업}은 제가 직접 처리할 수 없어요. 대신 {대안}을 도와드릴까요?"
