# 삼성증권 시스템 이용 관련 전반적인 질의를 할 경우

FAQ·이용 가이드 문서를 검색해 질의에 답한다.

## Instructions
1. 사용자 질의에서 검색할 주제·키워드를 파악합니다.
2. `faq_search` 툴을 호출해 모니모/관계사 FAQ와 이용 가이드를 검색해 관련 문서를 조회합니다.
3. 검색된 문서에서 질의에 해당하는 내용을 추출해 요약 안내하고, 관련 화면 이동 배너가 있으면 함께 제공합니다.
4. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

## 응답 가이드
- (고객센터 연동 데이터 기반으로 질의 답변)

## 예외 처리
- 문서 근거가 없는 내용은 답하지 않습니다(잘못된 안내 방지). 확인 가능한 채널을 대신 안내합니다.
- 조회 대상을 특정하지 못한 경우: 후보를 제시하거나 사용자에게 직접 확인합니다.
- 조회 결과가 없는 경우: 해당 내역이 없다는 사실을 안내하고 마칩니다.
- 응답에 사용자가 요청한 필드가 없는 경우: 제공 불가 사실을 알리고, 안내 가능한 다른 항목을 제안합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.
