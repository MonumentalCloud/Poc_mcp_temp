# 검색어 모호성 확인

모호한 검색어의 의도를 먼저 좁힌 뒤 해당 메뉴 경로를 안내한다.

## Instructions
1. 사용자 질의가 어떤 항목(예: 갤러/모니머니/카드포인트)을 가리키는지 후보를 정리합니다.
2. 후보 항목 확인 질문을 먼저 수행해 의도를 좁힙니다.
3. `menu_search` 툴을 호출해 모니모 앱 메뉴를 검색해 위치·이동 경로·딥링크·해당 메뉴에서 가능한 업무를 조회합니다.
4. 확인된 의도에 맞는 대표 서비스 메뉴와 이동 경로를 안내합니다.
5. 딥링크가 있으면 바로가기 배너로 제공합니다.
6. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

> 훅: 이 스킬은 `scripts/hook.py`를 제공합니다. 툴 호출 전 `before_tool`(파라미터 검증·실행형 가드), 호출 후 `after_tool`(오류·재시도 판단), 응답 전 `finalize`(문구 템플릿)를 실행하세요. MCP 서버의 `run_skill_hook` 툴로 원격 실행할 수 있습니다.

## 응답 가이드
- 포인트 종류(갤러/모니머니/카드포인트 등) 확인 질문 우선 수행
- 사용 가능한 대표 서비스 메뉴 안내
- 추가 의도 확인 후 해당 메뉴 경로 제공

## 예외 처리
- 조회 대상을 특정하지 못한 경우: 후보를 제시하거나 사용자에게 직접 확인합니다.
- 조회 결과가 없는 경우: 해당 내역이 없다는 사실을 안내하고 마칩니다.
- 응답에 사용자가 요청한 필드가 없는 경우: 제공 불가 사실을 알리고, 안내 가능한 다른 항목을 제안합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

## 유저향 최종 안내 문구
의도 확인: "어떤 포인트를 말씀하시는 걸까요? (갤러/모니머니/카드포인트)"
안내 성공: "{항목}은(는) {경로}에서 사용하실 수 있어요."
