# 질병, 사고 내용에 따른 상품 탐색

추가 질문으로 사용자 조건을 파악한 뒤 맞는 상품 후보를 안내한다.

## Instructions
1. 사용자 질의에서 이미 주어진 조건(목적·상황·선호 혜택)을 파악합니다.
2. 조건이 부족하면 목적·선호를 추가 질문합니다(임의 추정으로 상품을 단정하지 않습니다).
3. `product_recommend` 툴을 호출해 사용자 조건·선호(혜택, 목적 등)에 맞는 상품 후보를 조회합니다.
4. `product_detail` 툴을 호출해 상품 코드로 특정 상품의 상세 정보(보장내용/혜택/금리 등)를 조회합니다.
5. 각 후보 상품의 특징을 요약 안내하고, 상세/가입 화면 이동 배너를 제공합니다.
6. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

> 훅: 이 스킬은 `scripts/hook.py`를 제공합니다. 툴 호출 전 `before_tool`(파라미터 검증·실행형 가드), 호출 후 `after_tool`(오류·재시도 판단), 응답 전 `finalize`(문구 템플릿)를 실행하세요. MCP 서버의 `run_skill_hook` 툴로 원격 실행할 수 있습니다.

## 응답 가이드
- 핵건강보험 주요 보장내용
- 핵건강보험 상세내용 확인 가능한 화면 이동 배너 제공

## 예외 처리
- 특정 상품을 단정적으로 추천하지 않습니다(불완전판매 방지). 후보와 비교 정보를 제공하고 선택은 사용자에게 맡깁니다.
- 조회 대상을 특정하지 못한 경우: 후보를 제시하거나 사용자에게 직접 확인합니다.
- 조회 결과가 없는 경우: 해당 내역이 없다는 사실을 안내하고 마칩니다.
- 응답에 사용자가 요청한 필드가 없는 경우: 제공 불가 사실을 알리고, 안내 가능한 다른 항목을 제안합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

안내: "말씀하신 조건에는 {후보 상품들}이 있어요. 각각 {특징 요약}입니다."
