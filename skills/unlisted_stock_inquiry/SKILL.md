# 종목 검색 및 시세/정보 조회

비상장 종목 질의에 대해 비상장임을 안내하고 대안을 제시한다.

## Instructions
1. 사용자 질의에서 조회 대상 회사를 파악합니다.
2. `stock_item_inquiry` 툴을 호출해 특정 종목의 시세·회사정보·관련 뉴스를 조회합니다.
3. 조회 결과가 비상장이면 해당 회사가 비상장 주식임을 안내합니다.
4. 상장된 유사/관련 종목 확인을 제안하고, 종목발굴 화면 이동 배너를 제공합니다.
5. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

> 훅: 이 스킬은 `scripts/hook.py`를 제공합니다. 툴 호출 전 `before_tool`(파라미터 검증·실행형 가드), 호출 후 `after_tool`(오류·재시도 판단), 응답 전 `finalize`(문구 템플릿)를 실행하세요. MCP 서버의 `run_skill_hook` 툴로 원격 실행할 수 있습니다.

## 응답 가이드
- 문의한 종목이 비상장 주식임을 안내
- 상장된 종목에 대한 확인 제안
- 종목발굴 화면으로 이동배너 제공

## 예외 처리
- 조회 대상을 특정하지 못한 경우: 후보를 제시하거나 사용자에게 직접 확인합니다.
- 조회 결과가 없는 경우: 해당 내역이 없다는 사실을 안내하고 마칩니다.
- 응답에 사용자가 요청한 필드가 없는 경우: 제공 불가 사실을 알리고, 안내 가능한 다른 항목을 제안합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

## 유저향 최종 안내 문구
비상장 안내: "{회사명}은(는) 아직 상장되지 않아 주가 정보를 제공할 수 없어요. 관련 상장 종목을 찾아드릴까요?"
