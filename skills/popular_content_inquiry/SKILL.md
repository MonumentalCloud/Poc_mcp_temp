# 조회수 높은 인기소식 목록

관심소식·컨텐츠를 조회해 요약 안내하거나 해당 화면으로 연결한다.

## Instructions
1. 사용자 질의에서 조회 기준(인기/관심분야/특정 분야/특정 컨텐츠)을 파악합니다.
2. `content_list_inquiry` 툴을 호출해 인기소식 또는 관심분야별 컨텐츠 목록을 조회합니다.
3. 조회된 컨텐츠의 제목·내용을 요약 안내하고, 해당 컨텐츠/설정 화면 이동 배너를 제공합니다.
4. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

> 훅: 이 스킬은 `scripts/hook.py`를 제공합니다. 툴 호출 전 `before_tool`(파라미터 검증·실행형 가드), 호출 후 `after_tool`(오류·재시도 판단), 응답 전 `finalize`(문구 템플릿)를 실행하세요. MCP 서버의 `run_skill_hook` 툴로 원격 실행할 수 있습니다.

## 응답 가이드
- 조회수높은 인기소식 노출

## 예외 처리
- 관심분야 미설정 사용자인 경우: 설정 화면을 안내합니다.
- 조회 대상을 특정하지 못한 경우: 후보를 제시하거나 사용자에게 직접 확인합니다.
- 조회 결과가 없는 경우: 해당 내역이 없다는 사실을 안내하고 마칩니다.
- 응답에 사용자가 요청한 필드가 없는 경우: 제공 불가 사실을 알리고, 안내 가능한 다른 항목을 제안합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

## 유저향 최종 안내 문구
조회 성공: "오늘의 {기준} 소식이에요. 1. {제목1} — {요약1} ..."
결과 없음: "지금 보여드릴 {기준} 컨텐츠가 없어요."
