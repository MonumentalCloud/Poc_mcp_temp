# 상품 추천

직접 수행할 수 없는 요청임을 안내하고 가능한 대안을 제공한다.

## Instructions
1. 사용자 질의에서 요청 내용과 수행 불가 사유(정책/권한/데이터 범위)를 파악합니다.
2. 요청을 직접 수행할 수 없는 이유를 한 문장으로 정중히 안내합니다.
3. 수행 가능한 대안(관련 조회, 화면 이동, 객관적 정보 제공)을 제시합니다.
4. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

## 예외 처리
- 사용자가 대안을 원하지 않는 경우: 정중히 마무리합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

## 유저향 최종 안내 문구
제한 안내: "요청하신 {작업}은 제가 직접 처리할 수 없어요. 대신 {대안}을 도와드릴까요?"
