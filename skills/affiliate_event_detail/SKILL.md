# 이벤트 세부 내용 확인 (금융4사 이벤트)

특정 이벤트의 세부 내용을 조회해 안내한다.

## Instructions
1. 사용자 질의에서 대상 이벤트(이벤트명/키워드)와 묻는 항목(발표일/혜택 등)을 파악합니다.
2. `event_list_inquiry` 툴을 호출해 진행 중인 이벤트 목록을 회사·키워드 필터로 조회합니다.
3. `event_detail_inquiry` 툴을 호출해 특정 이벤트의 세부 내용(기간/혜택/발표일/응모방법)을 조회합니다.
4. 요약 정보와 사용자가 묻는 항목(발표일/혜택 조건 등)을 안내합니다.
5. 세부 기준은 이벤트 상세화면에서 확인하도록 배너를 제공합니다.
6. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

> 훅: 이 스킬은 `scripts/hook.py`를 제공합니다. 툴 호출 전 `before_tool`(파라미터 검증·실행형 가드), 호출 후 `after_tool`(오류·재시도 판단), 응답 전 `finalize`(문구 템플릿)를 실행하세요. MCP 서버의 `run_skill_hook` 툴로 원격 실행할 수 있습니다.

## 응답 가이드
- 연금저축보험 관련 이벤트 리스트 제공(이벤트 요약정보)
- 고객이 원하는 조건의 혜택정보 안내

## 예외 처리
- 대상 이벤트를 특정하지 못한 경우: 키워드로 조회된 후보 리스트를 제시하고 확인합니다.
- 조회 대상을 특정하지 못한 경우: 후보를 제시하거나 사용자에게 직접 확인합니다.
- 조회 결과가 없는 경우: 해당 내역이 없다는 사실을 안내하고 마칩니다.
- 응답에 사용자가 요청한 필드가 없는 경우: 제공 불가 사실을 알리고, 안내 가능한 다른 항목을 제안합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

## 유저향 최종 안내 문구
안내: "{이벤트명}의 {항목}은 {값}이에요. 세부 기준은 상세화면에서 확인해 주세요."
