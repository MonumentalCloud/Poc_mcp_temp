# 타사 카드 이용내역 조회

보유 카드의 이용내역·결제예정금액을 조회해 안내한다.

## Instructions
1. 사용자 질의에서 대상 카드와 조회 항목(이용내역/결제예정금액)·기간을 파악합니다.
2. `other_card_usage_inquiry` 툴을 호출해 마이데이터 소비내역 기반 타사 카드 이용금액을 조회합니다.
3. 조회 결과(이용내역/결제일/결제예정금액)를 안내합니다.
4. 기본 조회 기간(최근 2주)보다 과거 내역을 원하는지 확인합니다.
5. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

## 응답 가이드
- 자산 > 소비내역에서 문의한 카드이용내역 확인하여 안내

## 예외 처리
- 대상 카드를 특정하지 못한 경우: 보유 카드 목록을 안내하고 확인합니다.
- 조회 대상을 특정하지 못한 경우: 후보를 제시하거나 사용자에게 직접 확인합니다.
- 조회 결과가 없는 경우: 해당 내역이 없다는 사실을 안내하고 마칩니다.
- 응답에 사용자가 요청한 필드가 없는 경우: 제공 불가 사실을 알리고, 안내 가능한 다른 항목을 제안합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

## 유저향 최종 안내 문구
조회 성공: "{카드명}의 최근 2주 이용내역은 총 {건수}건, {금액}원이에요."
결제금액: "이번 결제일({일자})에 출금 예정인 금액은 {금액}원이에요."
