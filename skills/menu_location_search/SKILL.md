# 메뉴 위치 탐색

모니모 앱 내 메뉴 위치와 이동 경로를 찾아 단계별로 안내한다.

## Instructions
1. 사용자 질의에서 찾으려는 기능·메뉴 키워드를 파악합니다.
2. `menu_search` 툴을 호출해 모니모 앱 메뉴를 검색해 위치·이동 경로·딥링크·해당 메뉴에서 가능한 업무를 조회합니다.
3. 조회된 경로를 단계별로 안내하고, 해당 메뉴에서 가능한 업무를 함께 설명합니다.
4. 응답에 딥링크가 포함된 경우 바로가기 배너/버튼으로 제공합니다.
5. 아래 '응답 가이드'와 '유저향 최종 안내 문구'에 맞춰 결과를 안내합니다.

> 훅: 이 스킬은 `scripts/hook.py`를 제공합니다. 툴 호출 전 `before_tool`(파라미터 검증·실행형 가드), 호출 후 `after_tool`(오류·재시도 판단), 응답 전 `finalize`(문구 템플릿)를 실행하세요. MCP 서버의 `run_skill_hook` 툴로 원격 실행할 수 있습니다.

## 응답 가이드
- 메뉴 위치 정확히 안내 및 앱 내 이동 경로 단계별 제공
- 해당 메뉴에서 가능한 업무 안내
- 바로가기 배너/버튼 제공 가능 시 연결

## 예외 처리
- 검색 결과가 여러 메뉴에 걸치는 경우: 후보 메뉴를 제시하고 의도를 확인합니다.
- 조회 대상을 특정하지 못한 경우: 후보를 제시하거나 사용자에게 직접 확인합니다.
- 조회 결과가 없는 경우: 해당 내역이 없다는 사실을 안내하고 마칩니다.
- 응답에 사용자가 요청한 필드가 없는 경우: 제공 불가 사실을 알리고, 안내 가능한 다른 항목을 제안합니다.
- API 오류 또는 응답 지연: 자동으로 재시도하지 않습니다(중복 조회로 이어질 수 있으므로). 조회 미완료를 알리고 재시도 여부를 묻습니다.

## 유저향 최종 안내 문구
안내 성공: "{메뉴명}은(는) {경로}에서 확인하실 수 있어요. 아래 바로가기로 이동해 보세요."
결과 없음: "말씀하신 기능을 찾지 못했어요. 어떤 작업을 하려고 하시는지 조금 더 알려주시겠어요?"
